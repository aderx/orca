# ZStack 服务启动器

Orca 本地扩展版的独立插件，业务实现不进入宿主通用组件。当前面向 macOS 本机 ZStack worktree。

在受支持工作区右上角常驻 BFF / FE 图标，按钮尺寸、颜色与右侧栏按钮一致。点击打开专门的服务选择弹窗：顶部标题及产品选择，中间搜索与列表，底部启动/停止；保留服务器搜索、模块选择和定位。完整“服务”页只通过添加 TAB 菜单手动打开，不提供入口模式开关，也不自动打开服务 TAB。BFF 显示 IP、描述和实际 `.env` 对应的“当前”标签，浏览器按钮在当前 worktree 中新建并切换到浏览器 TAB，打开 `http://主机:5000`。选择其他主机不会立即改写环境。

FE 从 `scripts/start.ts` 的 `PRODUCT_CONFIGS` 和各产品 MF_CONFIG 读取产品与模块，产品显示为“Cloud（core-shell）”。模块按字母排列，右侧字母索引滚动定位；全选/取消选择作用于当前产品全部业务模块，搜索不影响范围，产品入口始终保留。模块名称后提供依赖选择。移除 MF Hub Proxy 开关，启动固定使用 `--proxy=false`；它原先启动的是 3200 代理，不是打开浏览器，Cloud Shell 自身端口为 3000。

FE 启动成功后显示“打开”，通过 macOS 系统默认浏览器访问本次启动的产品入口。入口端口取自当前产品目录并存入运行记录；旧记录按原产品与启动模块恢复地址，不使用页面后来选择的产品。准备、启动、停止和已结束时隐藏按钮，点击时再次校验运行 ID 与就绪状态。

BFF/FE 各自右上角提供图标和启动/停止文案。首次启动创建原生终端，停止后保留 TAB 和输出，再次启动优先复用同类服务的原终端。原 TAB 已关闭、归属记录不可用或发送命令失败时，先提示 toast，再为同一次启动请求新建终端；不放宽宿主归属校验，不关闭原 TAB。启动时通过插件的 `prepare-dependencies.py` 复用已安装 zs-start 的 `prepare_frontend_scope`，检查依赖闭包、先离线补齐链接，必要时自动联网重试，再按依赖顺序单并发构建缺失或过期产物，成功后才启动服务。BFF 使用 `--apps bff`；FE 使用所选模块。适配器直接传入真实产品和模块包名，跳过 zs-start 的交互菜单；安装和构建阶段使用 CI 环境与关闭的 stdin，不需要手动输入 y，不修改 zs-start 源码。

BFF 高级配置提供“SSH 转发”开关，默认关闭，随启动选择按 worktree / 产品保存。开启时将 HOST 草稿切换并锁定为 `127.0.0.1`，启动时强制写入该值；关闭开关恢复本次打开前的 HOST 草稿，若已保存为回环地址则可手动修改。运行器先使用系统 OpenSSH 连接所选 MN 的 root 账号，按约定用固定开发密码认证一次，不重试；转发建立后才准备依赖并启动 BFF。MN 的回环端口转发至本机相同端口，优先使用 `.env` 的 PORT，否则使用 BASE_PORT（默认 3100）加 INSTANCE_ID（默认 0）。认证、连接或端口绑定失败时停止启动并显示 toast。启动弹窗在终端提交成功后关闭；开启转发时还需等待转发建立。

SSH 使用独立连接，不复用其他 SSH 会话；首次主机密钥存于插件私有目录，已记录密钥变化时拒绝连接，不修改用户 SSH 配置。密码通过 askpass 提供，不进入命令行、运行记录或日志。服务正常退出、启动失败、停止及 Ctrl+C 均等待本次转发进程退出；转发意外断开会停止该次 BFF。运行器异常消失时，SSH 会话的 stdin EOF 让远端保活命令退出并释放监听。当前仍限定 macOS 本机工作区，没有新增远程工作区支持。

需要本机 Bun、pnpm 和已安装的 zs-start。页面打开只读取目录，不安装依赖或启动服务。终端展示启动和运行输出，保留现有落盘记录，不再提供单独的安装、终端或日志按钮。停止通过每次运行自己的控制文件终止其进程组；准备阶段停止不会继续启动服务。进程组结束后保留终端 TAB；无法确认停止时显示错误，不向终端发送下一条命令。

宿主需支持 commands.invoke、terminal.create、terminal.focusOwned、terminal.closeOwned、terminal.sendText、browser.open、workspace.readContext，以及 workspace-panel.<panelId>.probe 约定。2026-10-12 检查的 main（65a1611926）已有 terminal.sendText 和 workspace.readContext，但仍缺少上述命令调用、终端管理及浏览器打开接口，以及工作区上下文、工具栏弹窗和服务 TAB 扩展位。当前插件声明的 commands:invoke、terminal:manage、browser:open 会被该 main 的清单校验拒绝，不能原样安装到未扩展版本；业务逻辑本身仍保留在插件中。

开发与上游升级请读 ../../docs/readme/custom-fork-development.md。测试：node --test plugins/zstack-launcher/test.mjs；node plugins/zstack-launcher/panel.test.mjs。后者仅在源码仓库使用 happy-dom，不是插件运行依赖。

支持的本机工作树首次打开不自动创建服务 TAB 或空终端；历史入口开关不再控制显示。显式启动任务、普通/远程项目与已有终端保留原有行为。插件检测失败或超时会恢复默认终端。已有 Terminal 1 不会自动关闭，避免终止用户任务。

弹窗宽度由插件描述，BFF 为 384px，FE 为 448px；从加载占位开始按内容调整高度，并受窗口大小约束，不预留 480/540px 最大高度。编辑服务器时弹窗随表单增高，关闭后恢复列表高度。未启动或已结束时列表保持展开，不显示折叠按钮；服务启动中或启动后默认折叠，展开后才查询和渲染候选，折叠控件仅显示图标。已启动后显示弱化的重启按钮，准备和启动过程中隐藏；启动或重启请求成功提交至终端后关闭弹窗；SSH 转发启用时等待连接建立，失败保留表单。宿主在沙箱文档首次解析前注入展示模式，避免先绘制完整服务页再切换布局。弹窗四周保留 16px 间距，顶部操作和搜索框贴齐右侧内边距，输入框焦点环和列表选择边框有独立留白；不显示额外的“服务”跳转页脚。


BFF 与 FE 各自独立准备依赖和启动，不等待另一项服务；取消或停止其中一项不影响另一项。沿用 zs-start 单次准备内部的包构建顺序，不在两类服务之间增加排队。

折叠摘要仅显示本次启动记录中的 TAG/IP，不重复显示启动状态：FE 将全部启动模块（含产品入口）显示为 TAG，BFF 显示启动时的 IP；修改候选选择不会改变正在运行的摘要，也不会为摘要加载候选列表。重启请求携带列表最新勾选的模块，停止前先保存，展开或折叠时重启均使用这份选择。TAG 自动换行，内容较多时在摘要内滚动。启动中的按钮悬停或获得键盘焦点时，图标与文字一起切换为实心矩形和“停止”；移开或失去焦点后恢复加载图标和“启动中”。点击沿用取消启动流程。

两类服务分别维护请求状态，等待一个终端创建或服务停止不会锁住另一项启动按钮。启动请求及准备阶段显示旋转图标和“启动中”；请求返回后仍可点击取消准备，运行后显示实心矩形停止图标和“停止”，失败后恢复启动按钮。右上角黄点闪烁表示启动或停止中；BFF 收到 Nest 完成启动日志、FE 所选模块的端口全部由本次服务进程组监听后才显示绿点。启动成功结果记录在本次运行中，后续业务 ERROR、编译日志或短时端口变化不改变启动结果。仅启动失败或异常退出显示红点；无法核实进程或读取状态时显示灰点。异常内容统一交给 Orca 提示条，弹窗内不展示错误堆栈。状态点遵守减少动画设置。

16322 是项目 `@module-federation/dts-plugin` 的 Broker 默认 WebSocket 端口。运行器在父进程仍存在时核对它属于本次服务进程组，再记录 Broker 的 PID、启动时间和命令。停止后只清理身份仍匹配、没有客户端连接且没有其他插件服务在运行的 Broker；其他工作区仍使用时保留，最后一项服务结束时再次处理。未登记的进程、复用的 PID 和无法核实的状态不执行终止。旧版本留下的未登记 Broker 仍需先确认归属再清理。

BFF 与 FE 搜索框统一为 32px 高，有输入时显示一键清空按钮。搜索按字段忽略大小写、连续包含完整输入，不跨字符或跨字段匹配；输入停顿 300 毫秒后更新结果，中文组词期间不显示空状态。BFF 仅在非空搜索没有任何匹配候选时，在空态中展示“＋ 新增”；空搜索、有匹配候选（包括不可用地址）或输入尚未完成时均不显示。点击新增或输入完成按回车打开创建弹窗：完整 IP（含 HTTP/HTTPS URL）填入 IP，否则填入描述，并聚焦待补字段。新增保存时同时持久化当前 worktree 的选中项；新增和编辑成功后均清空搜索、定位并高亮保存后的记录，修改已选 IP 时同步更新选择；取消保留搜索。新增/编辑支持 IP 主机的 HTTP/HTTPS URL，保存时仅记录 IP。弹窗右下角排列取消、保存；编辑时左下角提供红色无边框的删除图标和文字，悬停有背景，删除需再次确认。候选列表操作不改写 `.env`。BFF 仅在未启动或运行已结束时在左下角展示“高级配置”折叠按钮，默认收起；启动、准备依赖、运行和停止过程中隐藏入口及配置区，禁止修改。弹窗展开高级配置时隐藏候选列表、搜索及列表操作，列表与高级配置使用 400px 内容区，随窗口可用高度缩小，停止状态下切换高级配置前后弹窗等高；运行摘要按 TAG/IP 内容缩短，不保留列表高度；内容独立滚动，底部启动按钮保持可见。收起后恢复原列表展开状态、搜索、选择和滚动位置。读取当前 worktree `.env` 的值与注释，筛选为本机服务（HOST、BASE_PORT）、MySQL（端口、用户名、密码）、Redis（地址、端口、TTL）、请求设置（ZS_ACTION_TIMEOUT）及调试与功能（API_INSPECTOR、INTERACTIVE_COLLECT、OPEN_PLATFORM）五组；字段缺失时不展示，HOST 保留可配置入口。原注释作为组或字段说明，密码使用密码输入框。内部路径、实例标识、反馈账号与 MOCK 配置不展示。ZS_MN_SERVER、ZS_MYSQL_HOST、ZOPS_SERVER 继续由上方服务器选择控制。

高级配置只编辑当前页面的草稿，折叠后保留输入；关闭页面后丢弃未提交修改。点击启动或重启才将实际改动字段与管理节点配置一并原子写入 `.env`，保留注释、未改动值和换行格式；不会自动检测网卡；仅在开启 SSH 转发时强制使用回环 HOST。HOST 输入框右侧提供“检测本机 IP”图标，仅点击时读取 macOS 网络服务顺序与当前网卡地址，优先选择已配置网络服务的 en* Wi-Fi/以太网 IPv4，排除 VPN、回环、链路本地及代理 Fake IP；读取服务顺序失败时仍从 en* 网卡中选择。没有可用地址时保留原输入并提示手动填写。检测结果只更新当前草稿，启动或重启时才写入。配置值不写入插件选择或运行记录。文件已被外部修改时拒绝覆盖，重启在停止原服务前检查冲突；携带高级配置修改的请求成功后才关闭弹窗，失败保留表单。仍不生成 `.bak`，继续拒绝符号链接环境文件。

FE 搜索左侧为三态全选、定位图标，右侧为产品下拉。全选图标在空选/部分选择时点击全选，全部选中时点击取消选择。无业务选择时，定位按钮先选择当前分支的变更模块；后续点击按字母顺序循环定位已选模块，清空搜索显示目标。没有已选模块且没有可选变更模块时禁用定位按钮，不显示提示。保留初始自动勾选逻辑。选择数量仅显示在“启动（N）”，不计入隐含的产品入口；无业务选择时显示“启动”并禁用，运行中的停止按钮不受此限制。


`browser.open` 需要独立的 `browser:open` 插件权限，只允许 worker 调用 HTTP/HTTPS 地址。宿主校验发起操作的 worktree 与当前工作区一致，然后向已有 browserTabCreate 传显式 worktree ID；切换工作区后拒绝延迟请求，不改到新工作区。无该接口的旧宿主不能启用新版启动器，需同步源码重建；不退回系统浏览器。

服务 TAB 首次显示时加载数据，切换到其他 TAB 或 worktree 时保留页面、搜索与滚动位置；隐藏期间暂停服务状态请求，再次显示只更新运行状态。模块及候选列表通过“刷新”重新读取，保存配置和切换产品仍按原流程更新数据。关闭 TAB 后释放页面，下次打开重新加载；应用刷新、主题切换或插件代码更新也会重建页面。

BFF 对尚未检测的地址后台请求一次 `http://IP:5000/`，结果保存在插件存储；重新打开、筛选、状态刷新、启动 BFF 或重载插件都复用已完成的结果，新增 IP 自动补测，手动点击重新检测才重测已有地址。HTTP 2xx/3xx 视为可访问，单次请求最多 2 秒，最多 8 个并发；检测不阻塞弹窗或启动状态。当前列表没有可用 IP 时显示居中空文案，不可用地址放在末尾独立的“不可用”分组；搜索保留检测分组，搜索结果没有不可用 IP 时不显示该组，BFF 不增加右侧导航。分组吸顶贴合滚动区域顶部，不保留顶部内边距。
